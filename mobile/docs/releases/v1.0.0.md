The first version of Buteo: a glide computer for Android phones, with
XCSoar's flight computer under a touch interface made for the cockpit.

> **A backup instrument.** Buteo is no certified instrument: never
> use it as your only source for navigation, airspace or traffic.
> It is not made by the XCSoar project; report its problems in this
> repository's issues.

## What is in it

- XCSoar's moving map with terrain, airspace, waypoints, the task and
  the trail
- Six tiles for cruise and six for circling, with any of XCSoar's
  InfoBoxes
- Vario and final glide bars; vario and speed to fly sound
- Tasks (`.tsk`, SeeYou `.cup`, WeGlide), Go to the nearest landables
- Airspace warnings with a banner, a tone and vibration; NOTAMs
- The thermal assistant while circling; spoken callouts
- IGC logging from take-off to landing, a flight summary, upload to
  WeGlide
- A first start that sets up units and the glider and downloads the
  map, airspace and airfields for where you are
- Your XCSoar profiles, planes and data files

Not there yet: external devices (Bluetooth, BLE and USB varios,
loggers, FLARM traffic). Coming from XCSoar: see
[Moving from XCSoar](https://github.com/CorentinGrard/buteo/blob/mobile/mobile/docs/MIGRATING.md).

## Install

Android 8 or newer, on a 64-bit ARM phone. Download
`buteo-1.0.0.apk` below on the phone, open it, and let the browser
install apps when Android asks. Buteo installs beside XCSoar; its
files are in `Android/data/app.corentin.buteo/files/XCSoarData`.

A test build installed before (signed with another key) cannot be
updated by this one: copy its `XCSoarData` folder somewhere, uninstall
it, then install this one and copy the folder back.
